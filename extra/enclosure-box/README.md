# Enclosure

This file describes the build process for modifying a box-style enclosure for the ENTS board.

## Instructions

1. Determine the number and size of cable glands and vents needed.

Typical installations may include:
- 1x USB
- 1x vent
- \>2x cable gland
2. Use the retaining nuts to find good locations on the bottom edge of the enclosure for the holes.
3. Mark the center of each hole with a marker.
4. Drill holes at the marked locations based on the hole diameter.
5. Install cable glands.
